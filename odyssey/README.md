# Odysseys × MatrAIx Personas

A MatrAIx persona holds an [Odysseys](https://odysseysbench.com/) task as its own need
and asks a computer-use agent (CUA) for help in its own words. The CUA does the task
in a real Chrome on the live web, and a judge grades the result against the task's rubric.

## Pipeline

| Role | Model | Input | Output |
|---|---|---|---|
| Persona LLM | `qwen/qwen3.8-27b` (OpenRouter) | persona profile + Odysseys task | the request in character; answers the CUA's questions |
| CUA | `qwen/qwen3.8-27b` (OpenRouter) | only what the persona says | browses, may `ask_user` ≤ 5 times, final answer |
| Judge | `gpt-5.5` (OpenAI) | task, conversation, actions, answer, open tabs | per rubric item: `met`, `communicated` |

These are the defaults in `run.py`. Don't change them, and don't change `--max-steps` (default 50).

The optional [Health suite](task_suites/health/README.md) adds suite routing,
controlled persona pairs and explicit Bedrock settings. Existing tasks and
model defaults remain available. Use `--suite health` with the commands in that
runbook instead of replacing `tasks.json` for Health.

- **Personas**: `personas/*.yaml`, generated by `make_personas.py` from 38 of the
  1,290 MatrAIx dimensions (`dimensions.json`). `travel-expert` and
  `elderly-novice` are examples. `none` is the control: the Odysseys text is sent
  verbatim.
- **Tasks**: `tasks.json`, numbered 1..N in file order.
- **Scores**: `score` = met / all rubric items. `score_communicated` = met / only
  the items that came up in the conversation.

## Setup

```bash
git clone git@github.com:MatrAIx-ai/PersonaCUABench.git && cd PersonaCUABench
pip install -r odyssey/requirements.txt   # also needs Google Chrome installed
cat > .env <<EOF                           # repo root, never commit
OPENROUTER_API_KEY=...
OPENAI_API_KEY=...
EOF
python3 odyssey/test_pipeline.py          # offline self-check
```

## Your job

**1. Branch.** Work only on your own branch. Don't push to `main`.

```bash
git checkout -b <your-name>
```

**2. Tasks.** Replace `odyssey/tasks.json` with your assigned tasks. Copy their
entries unchanged, by `task_id`, from
[`ljang0/Odysseys`](https://github.com/ljang0/Odysseys) `data/odysseys.json`.

**3. Personas.** Define 3–4 clearly different groups of people suited to your
tasks (e.g. domain expert / novice / elderly / student). In `make_personas.py`:
- set `DIMENSIONS` to the few dozen dimensions from `dimensions.json` that
  separate your groups;
- replace `PROFILES` with one entry per group. Each entry must set a value for
  every dimension, chosen from that dimension's allowed values (the script checks).

```bash
python3 odyssey/make_personas.py                             # writes personas/*.yaml
python3 odyssey/run.py --all --persona <name> --preview      # opening message only
```

Check the previews before running. Your personas should ask for the same task
in clearly different ways. If they don't, change the profiles.

**4. Run.** Every persona × every task, plus the `none` control:

```bash
PERSONAS="none <p1> <p2> <p3>" nohup bash odyssey/run_grid.sh > grid.log 2>&1 &
python3 odyssey/report.py                                    # tables
```

If it's interrupted, run the same command again. It picks up where it stopped.
For a single cell: `python3 odyssey/run.py --task 1 --persona <p1> --headless`.

**5. Push.** Push your tasks and personas to your branch. `results/` stays
gitignored and local -- send it separately, or push it only when asked:

```bash
git add odyssey/tasks.json odyssey/make_personas.py odyssey/personas
git commit -m "<your-name>: tasks + personas"
git push -u origin <your-name>
```

## Output

`odyssey/results/<task>/<persona>__<model>__<stamp>/result.json` (gitignored):
`run.conversation`, `run.trajectory`, `run.answer`, `run.open_tabs`, `run.stop_reason`,
`judgement.verdicts`, `judgement.score`, `judgement.score_communicated`.

Prompts live in `odyssey/prompts/*.md`, one per role, and are loaded at import:
`agent.md`, `persona_user.md`, `rubric_judge.md`, `experience_judge.md`. Each
file's leading HTML comment lists its placeholders and is stripped before the
text reaches a model.

Check a low score before you trust it. If the trajectory shows `403`, a captcha,
or empty page reads, the environment failed, not the agent. Rerun the cell and
tell us.
