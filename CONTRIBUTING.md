# Odysseys × MatrAIx Personas

A MatrAIx persona holds an [Odysseys](https://odysseysbench.com/) task as its own need
and asks a computer-use agent (CUA) for help in its own words. The CUA does the task
in a real Chrome on the live web, and a judge grades the result against the task's rubric.

## Pipeline

| Role | Model | Input | Output |
|---|---|---|---|
| Persona LLM | `qwen/qwen3.8-27b` (OpenAI-compatible endpoint) | persona profile + Odysseys task | the request in character; answers the CUA's questions |
| CUA | `qwen/qwen3.8-27b` (OpenAI-compatible endpoint) | only what the persona says | browses, may `ask_user` ≤ 5 times, final answer |
| Judge | Azure OpenAI deployment | task, conversation, actions, answer, open tabs | per rubric item: `met`, `communicated` |

These are the defaults in `run.py`. Don't change them, and don't change `--max-steps` (default 50).

- **Personas**: 24 task-specific profiles under `personas/*.yaml`, generated by
  `make_personas.py` from 43 MatrAIx dimensions.
- **Tasks**: `tasks.json`, numbered 1..N in file order.
- **Scores**: `score` = met / all rubric items. `score_communicated` = met / only
  the items that came up in the conversation.

## Setup

```bash
git clone git@github.com:MatrAIx-ai/PersonaCUABench.git && cd PersonaCUABench
python3 -m venv .venv
.venv/bin/pip install -r odyssey/requirements.txt  # also needs Google Chrome
cp .env.example .env                      # repo root, never commit
# Edit .env: set the Qwen base URL and the Azure endpoint/key/deployment.
# QWEN_API_KEY may stay empty when the Qwen server does not require auth.
.venv/bin/python odyssey/test_pipeline.py # offline self-check
```

## Your job

**1. Branch.** Work only on your own branch. Don't push to `main`.

```bash
git checkout -b <your-name>
```

**2. Tasks.** Replace `odyssey/tasks.json` with your assigned tasks. Copy their
entries unchanged, by `task_id`, from
[`ljang0/Odysseys`](https://github.com/ljang0/Odysseys) `data/odysseys.json`.

**3. Personas.** Define 3–4 clearly different groups of people suited to your
tasks (e.g. domain expert / novice / elderly / student). In `make_personas.py`:
- set `DIMENSIONS` to the few dozen dimensions from `dimensions.json` that
  separate your groups;
- replace `PROFILES` with one entry per group. Each entry must set a value for
  every dimension, chosen from that dimension's allowed values (the script checks).

```bash
.venv/bin/python odyssey/make_personas.py                    # writes personas/*.yaml
.venv/bin/python odyssey/run.py --all --persona <name> --preview  # opening message only
```

Check the previews before running. Your personas should ask for the same task
in clearly different ways. If they don't, change the profiles.

**4. Run.** Each task's three assigned personas:

```bash
nohup bash odyssey/run_grid.sh > grid.log 2>&1 &
.venv/bin/python odyssey/report.py                           # tables
```

If it's interrupted, run the same command again. It picks up where it stopped.
For a single cell: `.venv/bin/python odyssey/run.py --task 1 --persona <p1> --headless`.

The two ClawBench tasks use its native isolated harness. After configuring the
same model in `../ClawBench/models/models.yaml`:

```bash
.venv/bin/python odyssey/prepare_claw_cases.py
cd ../ClawBench
uv run clawbench-batch --models qwen/qwen3.8-27b \
  --cases-dir ../Persona-CUA/odyssey/claw_cases --all-cases \
  --harness codex --judge YOUR_AZURE_DEPLOYMENT --max-concurrent 1 --no-upload
```

**5. Push.** Push your tasks, personas and code or doc changes (for example README) to
your branch. **Never commit results.** `results/` is gitignored; do not force-add it.

```bash
git add odyssey/tasks.json odyssey/make_personas.py odyssey/personas README.md
git commit -m "<your-name>: tasks + personas"
git push -u origin <your-name>
```

## Output

`odyssey/results/<task12>/<c0|c1|c2|c3>/<persona>__<model>__<stamp>/result.json`:
`condition`, `run.conversation`, `run.trajectory`, `run.answer`, `run.open_tabs`, `run.stop_reason`,
`judgement.verdicts`, `judgement.score`, `judgement.score_communicated`.

Check a low score before you trust it. If the trajectory shows `403`, a captcha,
or empty page reads, the environment failed, not the agent. Rerun the cell and
tell us.
